Pre-group dedupe

Before grouping, tabs in the current window are compared by URL similarity. Tabs whose URL closely matches a newer tab are closed; the newest tab of each near-duplicate family survives. The comparison is local — nothing is sent to any model.

On Vivaldi native tab groups are never rendered in the UI, so tabs already in groups still count as unorganized there.

Privacy

When you click the toolbar icon, tab titles and URLs (origin and path only — no query parameters) are sent to OpenRouter for grouping. OpenRouter does not log prompts or completions by default. The developer logs are stored locally in this browser and never uploaded; they may contain tab titles and URLs you grouped, plus titles and URLs of all tabs read while selecting candidates. Dedupe logs additionally store the full URL (including query and hash) of every tab the pre-pass compared or closed, so closed tabs can be recovered manually — still stored locally only.

Developer logs

Runs record what was sent to the model and what it returned. Tab selection records every tab read in the window and which rule excluded it (pinned / already grouped / internal URL / …). Dedupe records every URL comparison of the pre-group dedupe pass and which tabs it closed. Stored locally, capped at ~5 MB (oldest dropped). Never uploaded.
