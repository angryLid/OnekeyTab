Privacy

When you click the toolbar icon, tab titles and URLs (origin and path only — no query parameters) are sent to OpenRouter for grouping. OpenRouter does not log prompts or completions by default.

Security note

Your API key is stored in plaintext in this browser's local extension storage. This is demo-grade storage — do not reuse a production key.
